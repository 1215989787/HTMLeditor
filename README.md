# HTMLeditor

所见即所得的 HTML 编辑器，专为解决大模型生成 HTML 页面的微调痛点而设计。

## 解决的问题

使用 ChatGPT、Claude 等大模型生成 HTML5 页面时，经常面临：
- **微调困难**：生成的页面难以精确匹配需求，反复对话调整消耗大量 token
- **Token 浪费**：每次修改都需要重新发送完整上下文，成本高昂
- **数据安全**：敏感内容通过云端 AI 反复处理存在泄露风险
- **效率低下**：在源码和预览之间来回切换，无法直观看到修改效果

HTMLeditor 让你在浏览器中直接编辑预览，**零 token 消耗，完全本地运行，数据不出浏览器**。

## 功能

- **所见即所得编辑** — 左侧预览区域可直接修改文字内容
- **实时源码同步** — 编辑预览时右侧源码面板自动高亮更新
- **全文搜索** — 预览区和源码区双向同步高亮，支持上下导航
- **一键下载** — 修改完成后下载最新 HTML 文件
- **拖拽上传** — 拖拽 HTML 文件到预览区即可加载

## 快速开始

1. 下载 `HTMLeditor.html`
2. 在浏览器中打开即可使用

无需安装、无需构建、无需后端服务。单个 HTML 文件，打开即用。

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+F` / `⌘F` | 打开搜索栏 |
| `Enter` | 跳转到下一个匹配项 |
| `Shift+Enter` | 回到上一个匹配项 |
| `Esc` | 关闭搜索 |
| `Ctrl+S` / `⌘S` | 下载修改后的文件 |

## 技术栈

- 纯 HTML + CSS + JavaScript，无框架依赖
- [Prism.js](https://prismjs.com/) 提供源码语法高亮
- MutationObserver + 轮询实现双向同步
- contentEditable 实现 WYSIWYG 编辑
